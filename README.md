# SCARP-Antarctic

Anonymous supplementary repository for the submitted manuscript.

## Dataset

The Antarctic dataset used in the experiments is provided separately because
the archive is approximately 3.7 GB.

- Dataset archive: `Antarctica_All.tar.gz`
- Anonymous dataset access: [OSF anonymized view-only link](https://osf.io/gz5v3/overview?view_only=e1c41970ea6d4eaa8ef64e9590655873)
